# Fichas OMR 2.5

Los PDF de esta carpeta son A4 horizontal, 297 × 210 mm.
Imprimir a tamaño real / 100%, sin ajustar a página.

37 posiciones para apellidos y nombres, 12 para colegio, seis grados y 15
preguntas con cinco alternativas. El alfabeto incluye Ñ y `_` para espacios.
Orden y hora se escriben a mano y se transcriben en la revisión.

Las fichas A5/A6 de OMR 2.0 no corresponden a este perfil de lectura.
La edición 2.5.3 incluye letras tenues, separadores cada cinco columnas y guías de sector.
